Fonctionnalités

Ce que fait l'application

🔐

Sécurité Multi-rôles

Face ID, 2FA, Admin / Manager / Vendeur avec permissions dédiées et historique des connexions.

📦

Gestion Stock Intelligente

Alertes automatiques, code couleur (rouge/orange/vert), historique et suggestions de réapprovisionnement.

📷

Scanner & IA Photo

Scan code-barres pour ajout rapide. Détection automatique du produit par photo via IA.

🛒

Caisse POS Complète

Vente rapide, remises, tickets imprimables, paiements espèces / carte / mobile.

📊

Dashboard & Rapports

KPIs temps réel, statistiques vendeurs, exports Excel / PDF / CSV automatisés.

👥

CRM Clients

Base de données, historique achats, programme fidélité et offres promotionnelles.

🌙

Dark Mode & Multi-langues

Mode sombre / clair, support Français / Arabe / Anglais, interface responsive.

📱

Notifications WhatsApp

Alertes stock, ventes et sécurité envoyées en temps réel via CallMeBot API.
