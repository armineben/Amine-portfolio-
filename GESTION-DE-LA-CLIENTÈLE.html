🏋️‍♂️ Système de Gestion de Salle de Sport & Suivi Calorique (VBA Excel)

Ce projet est une solution complète d'automatisation développée sous Excel VBA, conçue pour les professionnels du fitness et de la gestion de données sportives. L'outil combine une interface utilisateur "Premium" inspirée des tableaux de bord modernes avec une logique algorithmique pour le suivi des performances physiques.

✨ Points Forts du Projet

  • Automatisation Complète : Génération dynamique de feuilles de calcul, formatage automatique et gestion de base de données via macros VBA.
  • Design Premium : Interface haute performance utilisant une charte graphique contrastée (Anthracite et Jaune Vif) pour une lisibilité maximale.
  • Algorithmes de Suivi : Calculs intégrés du BMR (Métabolisme de Base), du déficit calorique et de la progression pondérale en temps réel.

🛠️ Fonctionnalités Techniques

1. Gestion des Membres (CRM)

Un onglet dédié à la base clients permettant de suivre les adhésions, les types de forfaits (Premium, Standard) et le statut des membres avec un archivage structuré.

2. Dashboard de Suivi "Calorie Amortization"

Inspiré des outils d'analyse de données avancés, ce module permet :

  • Le suivi quotidien du poids avec calcul de l'écart par rapport à l'objectif.
  • La visualisation du déficit calorique (Calories consommées vs brûlées).
  • Une mise en forme conditionnelle dynamique pour identifier visuellement les succès et les zones d'effort.

3. Planification d'Entraînement Dynamique

Génération de programmes journaliers variés incluant les groupes musculaires, les charges, les répétitions et les temps de repos, automatisée pour offrir une rotation fluide des exercices.

💻 Technologies Utilisées

  • Langage : VBA (Visual Basic for Applications)
  • Logiciel : Microsoft Excel
  • Concepts : Programmation orientée objet (Worksheets, Ranges), Mise en forme conditionnelle par code, Algorithmes mathématiques de santé.
